# Evaluation

Use for dedicated validation of an implementation, experiment, cleanup pass, or
release. Identify acceptance criteria, expected outcomes, useful metrics, and
regression checks before evaluating.

Report results and baseline comparison when available. Separate objective checks
from subjective review; identify regressions, unmet criteria, risks, and limits.
State a pass/fail decision, or exactly what must still be run or provided. Do not
claim completion without assessing the relevant acceptance criteria.

Do not fix findings while evaluating. Report the recommended correction; a fix
belongs to a separate IMPLEMENTATION workflow. Inside LOOP, make that transition
without another approval when the correction remains in scope.
